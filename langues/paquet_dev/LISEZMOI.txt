EN BREF :
  - Le son doit sortir côté navigateur (frontend), pas côté serveur.
  - Français  -> API Grok (déjà en place).
  - Soussou   -> jouer les fichiers audio de ce paquet (Grok ne fait pas le soussou).
  - Une seule fonction parler(service, etape, texte) qui choisit selon la langue.
  - Voir le guide pour le tableau étape -> fichier et le code d'aiguillage.
