N'ma SIM — Vérification d'identité

1 Scannez le recto de votre pièce

CNI, passeport ou carte d'électeur. Tenez la pièce bien à plat dans le cadre.

2 Scannez le verso (sauf carte d'électeur)

Retournez la pièce. Pour une carte d'électeur, passez cette étape.

3 Prenez un selfie

Regardez la caméra, visage bien éclairé, sans lunettes de soleil ni casquette.

4 Vérification

Nous vérifions votre identité. Cela prend quelques secondes.
